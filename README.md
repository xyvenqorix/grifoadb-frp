## 🦅 ¿Qué es GrifoADB?

**GrifoADB** es una herramienta desarrollada en Python para facilitar el uso de **Android Debug Bridge (ADB)** desde Windows.

Permite realizar diferentes tareas de diagnóstico y administración de dispositivos Android desde una interfaz sencilla.

## ⚡ Características

- 📱 Información del dispositivo
- 🔋 Estado de batería
- 💾 Almacenamiento
- 🤖 Versión de Android
- 📋 Modelo
- 🔌 Dispositivos ADB
- 🔄 Reinicio
- 📦 Aplicaciones instaladas
- 📸 Capturas de pantalla
- ⚙️ Acceso a Ajustes
- 🚀 ADB y Fastboot

## 🔐 Uso responsable

GrifoADB está pensado para **aprendizaje, educación, diagnóstico y administración de dispositivos propios o autorizados**.

> ⚠️ No utilices la herramienta en dispositivos sin autorización.

## 🛠️ Tecnologías

- 🐍 Python
- 🤖 Android ADB
- ⚡ Fastboot
- 🪟 Windows
