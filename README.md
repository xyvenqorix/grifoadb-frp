📱 ¿Qué es Grifo ADB FRP?

Grifo ADB FRP es una herramienta desarrollada para facilitar la conexión y gestión de dispositivos Android desde un ordenador Windows utilizando Android Debug Bridge (ADB).

El proyecto reúne diferentes funciones relacionadas con ADB dentro de una interfaz sencilla y práctica.

---

⚡ Características

- 📱 Detección de dispositivos Android
- 🔌 Conexión mediante ADB
- 🛠️ Herramientas para diagnóstico y mantenimiento
- 💻 Diseñado para Windows
- ⚙️ Comandos ADB integrados
- 🚀 Interfaz sencilla
- 🔄 Desarrollo continuo

🚀 Uso

1. Conecta el dispositivo Android mediante USB.
2. Instala los controladores correspondientes.
3. Activa las opciones necesarias en el dispositivo.
4. Ejecuta Grifo ADB FRP.
5. Comprueba que el dispositivo sea detectado.
6. Utiliza las funciones disponibles.

«⚠️ Utiliza la herramienta únicamente en dispositivos propios o cuando tengas autorización para realizar el mantenimiento.»
